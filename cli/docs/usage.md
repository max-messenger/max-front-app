# Возможности и использование

## Возможности

- **Копирование полной структуры проекта** — включая `src/`, `public/`, конфиги
- **Интерактивные промпты** — пошаговый ввод конфигурации с валидацией
- **Очистка примеров** — удаление `entities/dog`
- **Инициализация git** — автоматический `git init` + initial commit
- **Установка зависимостей** — автоматический `npm install`
- **Генерация README** — создаёт базовый README для нового проекта
- **Опциональная настройка тестов** — настраивает Vitest и добавляет для примера файлы с тестами функции и компонента
- **Dry-run режим** — показывает план действий (какие файлы будут скопированы/трансформированы/удалены, какие команды выполнены) без реальных изменений на диске
- **Генерация сущностей** — команда `generate entity` создаёт готовую FSD-структуру сущности (api, model, ui, mock) по одному имени

## Использование

```bash
node max-front-app/cli/dist/index.cjs my-new-project
# Или через npx
npx @maxhub/create-max-front-app my-new-project
```

CLI задаст вопросы:
1. Имя пакета (npm name)
2. Отображаемое имя (title в index.html)
3. Описание
4. Настроить тестирование с помощью Vitest?
5. Инициализировать git?
6. Установить зависимости?

## Опции командной строки

| Опция               | Описание                                                     |
|---------------------|--------------------------------------------------------------|
| `[project-name]`    | Имя директории нового проекта                                |
| `--template <path>` | Путь к шаблону (по умолчанию — `max-front-app`)                    |
| `--skip-prompts`    | Пропустить интерактивные промпты                             |
| `--no-git`          | Не инициализировать git                                      |
| `--no-install`      | Не устанавливать зависимости                                 |
| `--dry-run`         | Показать план действий без записи файлов и выполнения команд |
| `--quiet`           | Запуск без логов                                             |

### Режим без промптов (CI/скрипты)

```bash
node max-front-app/cli/dist/index.cjs my-new-project --skip-prompts --no-git --no-install
# Или через npx
npx @maxhub/create-max-front-app my-new-project --skip-prompts --no-git --no-install
```

### Dry-run (предпросмотр плана)

Режим `--dry-run` выводит план действий: какие файлы будут скопированы или трансформированы, какие примеры удалены, какие файлы-заглушки созданы, какие команды (`git init`, `npm install`, правки для Vitest) выполнены. Изменения на диск не применяются.

```bash
node max-front-app/cli/dist/index.cjs my-new-project --dry-run --skip-prompts
# Или через npx
npx @maxhub/create-max-front-app my-new-project --dry-run --skip-prompts
```

Удобно для отладки шаблона и аудита того, что CLI собирается сделать, перед реальной генерацией проекта.

## Какие файлы трансформируются

CLI автоматически заменяет значения в следующих файлах:

- `package.json` — поле `name`
- `index.html` — тег `<title>`
- `README.md` — заголовок и описание

## Проверка корректности

После создания нового проекта:

1. Проверьте `package.json` — имя пакета должно быть новым
2. Проверьте `index.html` — title должен быть новым
3. Создайте `.env` — в проекте присутствует .env.example
4. Запустите `npm run dev` — проект должен запускаться без ошибок
5. Запустите `npm run build` — сборка должна проходить успешно
