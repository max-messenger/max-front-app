# Разработка CLI

```bash
cd cli

# Установка зависимостей
npm install

# Сборка
npm run build

# Запуск без сборки (через tsx)
npm run dev -- my-new-project --skip-prompts --no-git --no-install

# Запуск в режиме показа без записи и копирования
npm run dev -- my-new-project --dry-run

# Запуск в режиме минимального логирования
npm run dev -- my-new-project --quiet

# Запуск собранной версии
npm start -- my-new-project
```
